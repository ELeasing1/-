# Сайт «Благо Дарю»

Сайт работает на GitHub Pages бесплатно. Тексты, цифры, фото и разделы меняются через админку: `адрес-сайта/admin/`.

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `content.json` | Все тексты, цифры, списки и пути к фото. Его меняет админка |
| `index.html` | Готовая страница. Админка пересобирает её сама при публикации, руками не править |
| `images/` | Фото (уже сжатые, без геоданных с телефона) |
| `video/` | Видео |
| `assets/` | Оформление и работа страницы (`site.css`, `site.js`, `render.js`) |
| `admin/` | Админка |

## 1. Загрузить сайт на GitHub (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите **New repository** (зелёная кнопка или «+» вверху справа).
   - Repository name: например, `blago-daryu`.
   - Выберите **Public** (бесплатный GitHub Pages работает только с открытыми репозиториями).
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**.
4. Откройте папку `blago-daryu-site` на компьютере, выделите **всё её содержимое** (Ctrl+A) и перетащите в окно браузера. Перетаскивать нужно содержимое, а не саму папку, чтобы `index.html` оказался в корне репозитория.
5. Дождитесь, пока загрузятся все файлы (около 80 штук, ~56 МБ), и нажмите **Commit changes**.

Если браузер капризничает с большим количеством файлов, загрузите в два захода: сначала всё, кроме папок `images` и `video`, потом эти две папки. Или поставьте программу [GitHub Desktop](https://desktop.github.com) и перенесите папку через неё.

## 2. Включить сайт

1. В репозитории откройте **Settings → Pages**.
2. В блоке **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. Нажмите **Save**.
3. Через 1–2 минуты сверху появится адрес сайта, вида `https://ваш-логин.github.io/blago-daryu/`.

## 3. Получить токен для админки

Токен — это ключ, по которому админка сохраняет изменения в ваш репозиторий.

1. Откройте [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new).
2. **Token name**: например, «Админка сайта». **Expiration**: например, 1 год.
3. **Repository access** → **Only select repositories** → выберите репозиторий сайта.
4. **Permissions** → **Repository permissions** → **Contents** → **Read and write**.
5. Нажмите **Generate token** и скопируйте его. GitHub покажет токен только один раз.

Токен никому не пересылайте. Если он мог попасть в чужие руки, удалите его на той же странице GitHub и создайте новый.

## 4. Работать в админке

1. Откройте `https://ваш-логин.github.io/blago-daryu/admin/`.
2. Вставьте токен. Репозиторий подставится сам. Нажмите **Войти**.
3. Слева — разделы сайта сверху вниз. Их можно переставлять стрелками, скрывать галочкой «Показывать на сайте», удалять и добавлять новые (внизу списка).
4. **Общие настройки** — телефон, ссылки на ВКонтакте и MAX, логотип, цена стакана кофе для калькулятора, показывать ли ИНН, тексты для поисковиков.
5. Фото можно загружать прямо с телефона или компьютера, по одному или сразу пачкой («Добавить несколько фото»). Админка сама уменьшит их до 1600 пикселей.
6. **Предпросмотр** показывает сайт с вашими правками до публикации, в том числе как он выглядит на телефоне.
7. **Опубликовать** отправляет всё на GitHub одним сохранением. Сайт обновится через 1–2 минуты.

Пока вы не нажали «Опубликовать», правки хранятся в черновике на этом устройстве. Если закрыть вкладку, при следующем входе админка предложит его восстановить. Кнопка **Копия** скачивает `content.json` с текущими правками — на всякий случай.

## Полезно знать

- **Видео** лучше загружать до 25 МБ: тяжёлое видео долго грузится на телефоне. GitHub не примет файл больше 100 МБ.
- **Фото с iPhone** в формате HEIC браузер не открывает. Сохраните их как JPG (или в настройках камеры выберите «Наиболее совместимый»).
- **Свой домен** (например, `blago-daryu.ru`) подключается в **Settings → Pages → Custom domain**. После этого впишите адрес в админке: «Общие настройки» → «Адрес сайта».
- Если кто-то поправит `content.json` прямо на GitHub, минуя админку, сайт всё равно покажет свежие данные: страница сама пересоберётся при открытии.
- История всех изменений видна в репозитории во вкладке **Commits**. Любую версию можно вернуть.
